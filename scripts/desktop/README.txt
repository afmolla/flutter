Ayfleks - Masaustu calistirma
=============================

Bu klasoru Windows masaustundeki "site" klasorune kopyalayin.

Hizli baslangic (Windows):
1) Node.js LTS kurulu olsun (https://nodejs.org)
2) scripts\desktop\KUR.bat  -> cift tik (ilk sefer)
3) scripts\desktop\BASLAT.bat -> cift tik

Site: http://localhost:3000
Panel: http://localhost:3000/panel  (sifre: demo123)

Git ile guncelleme (PowerShell, Desktop\site icinde):
  git pull origin cursor/ayfleks-site-build-62ed
  npm install

Not: C:\ diski yerine Desktop\site kullanin; yazma izni sorunu olmaz.
